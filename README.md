# Healthcare App with AI/RAG Assistant

This repository is a cleaned portfolio version of a healthcare web application project.  
The original project includes healthcare e-commerce features such as product browsing, authentication, cart/order management, admin/pharmacist workflows, and health-related services.

For portfolio presentation, this version highlights the parts related to:

- Healthcare product data
- AI chatbot integration
- Retrieval-Augmented Generation (RAG)
- Product/FAQ-based question answering
- Chatbot UI and backend API integration

## My Main Contribution

My main contributions focused on:

- Preparing and structuring healthcare product data
- Working with product/FAQ data used for AI-based retrieval
- Building or integrating chatbot UI components
- Implementing part of the AI chat controller and chatbot workflow
- Supporting RAG-based retrieval for healthcare/product-related questions

This is a cleaned portfolio version of an older team project.
